# Canonical Question ID

Format:

`LGS-{YEAR}-{BOOKLET}-{SUBJECT}-{QUESTION_NUMBER}`

Examples:

`LGS-2026-SOZEL_A-TURKCE-01`
`LGS-2026-SAYISAL_A-MATEMATIK-01`

MEB sample:
`MEB-SAMPLE-{PERIOD}-{SUBJECT}-{SEQ}`

AI:
`AI-{CURRICULUM_VERSION}-{SUBJECT}-{UUID}`

A question's source identity and its curriculum mapping are separate.
